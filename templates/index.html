About This Project

ReturnImpact was created as part of an academic project combining logistics engineering, sustainability, and modern web development. The platform helps companies make informed decisions about product returns by understanding both the financial and environmental impact.

  • Tracks return costs and operational impact
  • Calculates multimodal CO₂ using real API models
  • Turns emissions into practical sustainability equivalents
